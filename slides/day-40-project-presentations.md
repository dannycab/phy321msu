# Submission Instructions

Your zipped folder must include:

- `README.md` – Overview of your project (team members, project title)
- `slides.pdf` – Your presentation slides
- `essay.ipynb` – Jupyter Notebook
- `essay.pdf` – PDF export of notebook
- `data/` – All datasets used
- `images/` – Any figures or media referenced
- `requirements.txt` – If you used non-standard libraries

---

# Folder Structure Example

```
FinalProject_GroupName/
    README.md
    slides.pdf
    essay.ipynb
    essay.pdf
    data/
    images/
    requirements.txt
```

---

# Before You Submit

* Run all cells in a **fresh environment** – confirm reproducibility
* Use **relative paths** for data/images
* Ensure plots and outputs are visible in the PDF
* Check that all supporting files are included

---

# Best Practices

* Clear folder organization
* Self-contained code (no hard-coded paths)
* Markdown cells for explanations
* Comment your code for clarity
* Include `requirements.txt` for extra libraries
* Descriptive file names (lowercase, no spaces)

---

# Why This Matters

Reproducibility and clarity are essential in computational physics. These practices ensure:

* Your work can be understood and verified
* You develop professional habits for research and collaboration
